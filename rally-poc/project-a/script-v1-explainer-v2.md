# Video 1: OpenScreen — Explainer (v2 - mixed media)

**Project:** OpenScreen
**Style:** Explainer
**Target Duration:** ~50 seconds
**Aspect Ratio:** 9:16 (1080x1920)

---

## Shot List

### Shot 1: HOOK (3s)
- **Asset type:** TEXT-TO-VIDEO
- **Prompt:** "Close-up of a laptop screen showing a subscription payment page, the price $29/month glows red, camera slowly pushes in, dramatic moody lighting, dark desk environment"
- **VO:** "Stop paying twenty-nine dollars a month for screen recording."
- **Why T2V:** Motion grabs attention. A static price card doesn't stop scrolls — a cinematic reveal does.

### Shot 2: CONTEXT (8s)
- **Asset type:** IMAGE-TO-VIDEO (animate NB2 image)
- **NB2 prompt:** "Screenshot of a professional screen recording application called OpenScreen. Dark theme editor UI showing video preview, editing controls for zoom and motion blur, timeline at bottom, Export Video button. Modern dark UI."
- **Video prompt:** "The UI elements subtly animate, cursor moves across the interface, buttons highlight, timeline playhead moves right, smooth professional software demo feel"
- **VO:** "OpenScreen does everything Screen Studio does. Auto-zoom, motion blur, smooth cursor. And it's completely free."
- **Why I2V:** Shows the product feeling alive and real, not a static screenshot.

### Shot 3: CONCEPT HERO (12s)
- **Asset type:** TEXT-TO-VIDEO
- **Prompt:** "Screen recording of a sleek dark code editor, a cursor clicks on a function name and the view smoothly auto-zooms into that area with cinematic motion blur, the zoom is silky smooth with bezier curve motion, professional screen recording demo, dark theme IDE"
- **VO:** "Click anywhere and it auto-zooms. Every movement gets motion blur. Your cursor flows instead of jumping. This is what a three hundred dollar per year tool looks like — for zero dollars."
- **Why T2V:** The auto-zoom feature IS the product. Showing it as actual motion is infinitely more compelling than a still.

### Shot 4: EVIDENCE (8s)
- **Asset type:** IMAGE-TO-VIDEO (animate NB2 image)
- **NB2 prompt:** "Dark tech dashboard showing GitHub statistics. Large glowing green text 26,100 STARS in center. Hockey stick growth chart below. MIT License badge. macOS, Windows, Linux platform icons at bottom."
- **Video prompt:** "The growth chart line animates upward in a hockey stick curve, the star count ticks up, platform icons glow one by one, data visualization comes alive"
- **VO:** "Twenty-six thousand developers starred it in a week. It's MIT licensed. It works on Mac, Windows, and Linux."
- **Why I2V:** Animated data viz is more engaging than static. The hockey stick chart drawing itself is satisfying to watch.

### Shot 5: COMPARISON (15s)
- **Asset type:** NB2 STILL (Ken Burns zoom)
- **NB2 prompt:** "Two-column comparison infographic. Left: red tint, Screen Studio, $348/year, Mac Only, Closed Source. Right: green tint, OpenScreen, $0/year, All Platforms, Open Source. Feature checklist below with green checkmarks."
- **VO:** "Same auto-zoom. Same motion blur. Same backgrounds and webcam overlay. But OpenScreen runs everywhere and costs nothing. A solo developer built this because he thought screen recording shouldn't cost three hundred and fifty dollars a year."
- **Why STILL:** Dense text comparison needs to be readable. Video motion would distract from the information. This is a "study it" shot.

### Shot 6: PAYOFF (3s)
- **Asset type:** IMAGE-TO-VIDEO (animate NB2 image)
- **NB2 prompt:** "Minimalist dark background, centered OpenScreen logo with blue glow, github.com/openscreen text below, clean tech branding"
- **Video prompt:** "The logo gently pulses with a soft blue glow, subtle particles drift upward, premium brand reveal feel"
- **VO:** "OpenScreen. Free forever. Link in bio."
- **Why I2V:** Logo reveals look cheap as stills. Even subtle motion makes the closer feel polished.
