# Video 1: OpenScreen — Explainer

**Project:** OpenScreen (free Screen Studio alternative)
**Style:** Explainer ("here's how X works in 60 seconds")
**Target Duration:** 32 seconds
**Aspect Ratio:** 9:16 (1080x1920)

---

## Shot List

### Shot 1: HOOK (2s)
- **Type:** hook
- **Visual:** Split screen — left side shows Screen Studio pricing page "$29/mo", right side shows OpenScreen GitHub page with star count "26,100". Red X over the price, green checkmark over OpenScreen. Bold text overlay: "STOP PAYING FOR SCREEN RECORDING"
- **VO:** "Stop paying twenty-nine dollars a month for screen recording."
- **FLUX prompt direction:** Split comparison graphic, dark background, left side showing a pricing card with $29/month crossed out in red, right side showing a GitHub repo page with green checkmark, tech infographic style, clean flat design, 9:16 vertical
- **Notes:** Hook must create instant recognition of the pain point (paying for screen recording). The price cross-out is the visual anchor.

### Shot 2: CONTEXT (4s)
- **Type:** context
- **Visual:** Screenshot of OpenScreen's editor UI (use real screenshot from repo — public/preview4.png). Subtle slow zoom in. Text overlay: "OpenScreen — Free & Open Source"
- **VO:** "OpenScreen does everything Screen Studio does. Auto-zoom, motion blur, smooth cursor. And it's completely free."
- **FLUX prompt direction:** N/A — use real screenshot
- **Notes:** This establishes credibility. The editor UI looks professional and expensive — the reveal that it's free is the subtext.

### Shot 3: CONCEPT HERO (8s)
- **Type:** concept_hero
- **Visual:** Screen recording simulation showing OpenScreen in action — a cursor clicking on a button, the view auto-zooming into the click area with motion blur. Stylized/recreated version. Text overlays appearing in sequence: "Auto-Zoom" → "Motion Blur" → "Smooth Cursor"
- **VO:** "Click anywhere and it auto-zooms. Every movement gets motion blur. Your cursor flows instead of jumping. This is what a three hundred dollar per year tool looks like — for zero dollars."
- **FLUX prompt direction:** Stylized screen recording UI showing a zoom effect on a dark interface, motion blur trails visible, cursor with smooth bezier path overlay, futuristic tech aesthetic, 9:16 vertical, neon accent colors on dark background
- **Notes:** This is the money shot. Show the core value prop in action. Multiple text overlays reinforce features while VO delivers the price comparison punchline.

### Shot 4: EVIDENCE (5s)
- **Type:** evidence / proof_card
- **Visual:** GitHub stats card — "26,100 stars", "10,000+ stars in one week", "46 contributors", "MIT License". Star growth chart (hockey stick). Text overlay: "Fastest growing open source project this week"
- **VO:** "Twenty-six thousand developers starred it in a week. It's MIT licensed. It works on Mac, Windows, and Linux."
- **FLUX prompt direction:** Dark tech dashboard showing GitHub statistics, star count 26100 in large font, hockey stick growth chart glowing green, MIT license badge, platform icons for macOS Windows Linux, data visualization aesthetic, 9:16 vertical
- **Notes:** Proof anchor. Real numbers build credibility. The cross-platform angle is the differentiation (Screen Studio is Mac only).

### Shot 5: CONCEPT HERO 2 (8s)
- **Type:** concept_hero
- **Visual:** Side-by-side comparison. Left: "Screen Studio — $348/year, Mac only, Closed source". Right: "OpenScreen — $0/year, All platforms, Open source". Features checklist with both getting green checks for auto-zoom, motion blur, backgrounds, webcam overlay. OpenScreen also gets checks for Linux, Windows.
- **VO:** "Same auto-zoom. Same motion blur. Same backgrounds and webcam overlay. But OpenScreen runs everywhere and costs nothing. A solo developer built this because he thought screen recording shouldn't cost three hundred and fifty dollars a year."
- **FLUX prompt direction:** Comparison infographic, two columns on dark background, left column red-tinted with Screen Studio logo and price, right column green-tinted with OpenScreen logo and $0, feature checklist with green checkmarks, clean minimal design, 9:16 vertical
- **Notes:** The direct comparison is the proof. The "solo developer" angle adds the underdog narrative. This is where viewers decide to share.

### Shot 6: PAYOFF (5s)
- **Type:** payoff
- **Visual:** OpenScreen logo centered, GitHub URL below. Text overlay: "Link in bio" and "github.com/siddharthvaddem/openscreen". Subtle particle effect background.
- **VO:** "OpenScreen. Free forever. Link in bio."
- **FLUX prompt direction:** Minimalist dark background with centered OpenScreen logo, GitHub URL text below, subtle glowing particles, clean tech branding, 9:16 vertical
- **Notes:** Clean exit. CTA is simple. Don't oversell.

## Audio Strategy
- **Voice:** ElevenLabs — clear, slightly energetic male voice. Not hype-y, but confident.
- **Pacing:** Fast but not breathless. Fireship-adjacent. Each sentence lands before the next starts.
- **Music:** Low-volume instrumental bed. Electronic/ambient. Under VO at all times.

## Text Overlays (CapCut)
- Hook text: Bold, centered, large font
- Feature labels: Animated in on beat
- Stats: Large numbers with subtle glow
- CTA: Clean, minimal
