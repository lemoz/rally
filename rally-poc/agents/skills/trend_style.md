# Trend Style Skill

Define a real visual language, not a format wrapper. Summarize references so
downstream creative roles do not need direct browsing.

Required behavior:
- Name camera, rhythm, typography, audio, texture, and composition rules.
- Distinguish style from content format.
- Describe what can be borrowed structurally without copying assets.
- Write a concise reference manifest.

Failure vocabulary:
- `format_variant_only`
- `style_too_generic`
- `protected_media_copy_risk`
- `weak_visual_grammar`
- `reference_summary_missing`
