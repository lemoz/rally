# Creative Director Skill

Create competing concepts and select the one with the strongest stop-scroll
promise. Work only from source and trend summaries.

Required behavior:
- Pitch at least two concepts.
- Make the first two seconds concrete.
- Explain why a stranger keeps watching.
- Reject concepts that are accurate but boring.

Failure vocabulary:
- `weak_hook`
- `no_audience_promise`
- `boring_but_correct`
- `style_not_integrated`
- `concept_not_source_safe`
